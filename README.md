Отладка приложения в Microsoft Visual Studio

### 1. Точки останова и пошаговое выполнение
- Установлены точки останова (F9) в методе BtnCalculate_Click для анализа логики при нажатии кнопки «Вычислить».
**Использовано пошаговое выполнение (F10 — Step Over, F11 — Step Into) для:**
- проверки условий валидации входных данных;
- отслеживания расчёта стоимости в методе CalculateCost;
- анализа работы вспомогательных методов IsAnyDaySelected() и IsWeekendSelected().
### 2. Мониторинг состояния переменных
**В окне Locals отслеживались текущие значения:**
- duration и pricePerMinute после преобразования из строк;
- промежуточных расчётов в CalculateCost (первые 30 минут, дополнительные минуты, итоговая стоимость).
**Через окно Watch контролировались ключевые выражения:**
- TxtDuration.Text, TxtPrice.Text — исходные входные данные;
- totalCost — итоговая сумма перед выводом.
### 3. Обработка исключений
**Активирована опция Common Language Runtime Exceptions в Exception Settings для автоматического прерывания на:**
- ошибках преобразования типов (double.TryParse);
- возможных NullReferenceException при обращении к элементам интерфейса.
- Это позволило оперативно выявлять некорректные входные данные и логические ошибки в условиях.
### 4. Анализ потока выполнения
**Окно Call Stack использовалось для:**
- подтверждения последовательности вызовов: BtnCalculate_Click → CalculateCost → вспомогательные методы;
- диагностики ветвлений в логике (проверка будних/выходных дней, расчёт скидок).
- Окно Output помогало отслеживать системные сообщения и возможные предупреждения компилятора.
